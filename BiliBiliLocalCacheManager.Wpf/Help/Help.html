BiliBili Local Cache Manager 使用帮助

软件用途

本工具用于扫描、搜索、播放和管理本地 B 站缓存。它读取已有缓存，不负责从 B 站下载视频。

快速开始

  1. 点击 浏览 选择缓存根目录（如 D:\BilibiliDownload），选完会自动扫描。下次启动会记住这个目录并自动扫描。
  2. 在 关键词 中输入文本即可实时过滤；按回车立即搜索，清空关键词则显示全部。
  3. 选择缓存后，双击行即可播放；多选后点击 播放所选 创建队列，再用 播放下一项 逐项推进。
  4. 需要把视频拷走或分享时，点击 导出 MP4（或右键菜单）保存成普通 MP4 文件。
  5. 确认无误后，可点击 删除 移至应用回收站；需要时点击 撤销删除 恢复。
  6. 在 存储管理 中查看三类占用、预计可释放空间，并按需清理转码缓存或应用回收站。

怎么找到我的缓存目录

本工具读取的是 B 站客户端下载到本机的缓存，需要你指出它存放的位置。

  • PC 客户端：在客户端的设置 → 下载设置中可以看到当前的下载路径，把该路径填进来即可。
  • 手机导出：把手机上 B 站的下载目录整体复制到电脑，再选择复制后的根目录。
  • 怎样算选对了：正确的根目录下面应当是一堆以数字命名的子目录（每个数字是一个 avid）， 再往下才是分段目录和 entry.json。如果你看到的是视频文件而不是数字目录，说明选深了一层。

导出为 MP4

  • 入口：底部 导出 MP4 按钮，或在缓存列表、分段详情上右键选择导出（快捷键 Ctrl+E）。
  • 单条：弹出另存对话框，默认文件名取自视频标题。
  • 多条：先选择一个目标文件夹，然后按“标题”命名；分 P 视频会命名成“标题 - P2 分段名”。 文件名中的非法字符会被替换，重名会自动追加 (2)。
  • 速度：导出复用播放用的转码产物。之前播放过的内容通常立刻就能导出；没转码过的会先转码， 期间状态栏显示进度，可以点 取消 中止。
  • 导出只会复制，不会移动或删除原始缓存，也不会删除转码缓存中的产物。

键盘快捷键

  • F5 扫描　Ctrl+F 聚焦关键字框　Enter（在关键字框内）立即搜索
  • Delete（在缓存列表内）删除所选　Ctrl+Z 撤销删除　Ctrl+E 导出 MP4
  • Esc 取消当前操作　双击列表行直接播放

搜索功能详解

搜索基于当前索引进行。如果你直接点击 搜索，程序会在必要时先扫描缓存目录。

  • 关键词输入：支持单词或短语。若勾选 分词，会按空格/换行等分隔符拆分关键词。
  • 匹配模式：
    • 包含：字段包含关键词即可命中。
    • 相等：字段需完全相等。
    • 前缀：字段以关键词开头。
    • 后缀：字段以关键词结尾。
  • 任意关键词：勾选后为“任意命中”（OR）；不勾选则为“全部命中”（AND）。
  • 搜索范围：标题默认参与搜索，你可以额外勾选 分段名 / UP 主 / Bvid / Avid。
  • 大小写敏感：勾选后严格区分大小写（对英文/BV 号更明显）。
  • 包含未完成缓存：影响索引范围，决定搜索是否包含未完成下载。

示例

  • 关键词：原神 教学，勾选分词、取消“任意关键词” → 标题需同时包含两个词。
  • 关键词：BV1xx，勾选“包含Bvid”，匹配模式选“相等” → 精确查 BV 号。
  • 关键词：123456，勾选“包含Avid” → 直接按 Avid 查找。
  • 关键词：某UP主，勾选“包含UP主” → 按 UP 名称过滤。

扫描报告

单个损坏的 entry.json 不会中断整个扫描。状态栏会显示当前进度、收录分段、跳过的未完成分段、无效条目和不可访问目录数量；扫描或自动建立搜索索引时可以点击 取消。

播放与转码缓存

分离的音视频或旧版片段会通过 FFmpeg 整理为可播放文件。源媒体未变化时，相同视频再次播放会直接复用持久化产物；缓存命中不会显示 FFmpeg 进度窗口。

默认保留 30 天、容量上限 20 GB。主界面可设置 保留天数（1–1825，最长 5 年）和 容量上限 (GB)（1–128）；失焦后自动保存，并用于下一次手动或后台维护。

程序会先显示主窗口，再在后台执行启动维护；播放器成功启动后也会请求一次后台维护。刚创建、刚复用和本次运行中最近交给播放器的产物会受到临时保护；保护集合最多 8 项、最长 24 小时，并受容量上限约束（最新一项除外）。

打开缓存 可查看受管目录；按策略清理 会删除过期项并从最旧产物开始压缩占用；一键清空 会在确认后删除全部可安全删除的受管转码产物，正在生成的文件会保留。这些操作不会删除 B 站原始缓存。

FFmpeg 首次下载、校验、解压或开始处理后会弹出进度窗口，显示当前阶段、完成百分比、已用时间和预计剩余时间。点击 取消转码 或关闭窗口会停止处理，且不会启动播放器。

如果其他实例正在生成同一播放缓存，也会显示可取消的等待进度；没有锁冲突的缓存命中不会弹窗。

程序默认使用与 CI、Release 相同清单固定的 FFmpeg 月末长期保留构建和 SHA-256，不会被 PATH 中的任意版本覆盖；系统 FFmpeg 仅在显式启用时使用。

受管目录：%LOCALAPPDATA%\BiliBiliLocalCacheManager\TranscodeCache

存储管理

“存储管理”同时显示 B 站原始缓存、转码缓存和应用回收站的数量与占用，并汇总受管总空间及按当前策略预计可释放的空间。

统计在后台执行。更换缓存根目录、调整策略或再次点击 刷新 时，旧统计会被取消或丢弃，不会覆盖新目录的结果。扫描、删除、撤销和彻底清空完成后，列表操作会先恢复可用，再刷新存储数据。

播放队列与播放器

播放所选 会建立页面队列并启动第一项，不会一次打开多个播放器。使用 播放下一项 推进，使用 清空队列 放弃剩余项目。

播放器偏好、缓存根目录和转码缓存策略会自动保存到本机用户设置。

安全删除

WPF 删除默认把所选缓存移动到根目录下的应用回收站，不会立即永久清除。点击 撤销删除 可以恢复最近一次删除；在“存储管理”的应用回收站区域点击 打开回收站 可查看其目录。

彻底清空 会在确认后永久删除其中由本应用管理的条目，其他未知条目会保留；该操作不可撤销。

同一缓存根目录的删除、恢复与彻底清空会在多个应用实例之间串行执行，避免恢复出只剩部分文件的缓存。

命令行 delete 与界面一致，默认移入应用回收站，可用 trash restore <avid> 还原； 只有显式加 --permanent 才会永久删除。两种路径都会先确认，脚本中请加 --yes。

设置兼容与诊断导出

用户设置带有版本号。旧设置会自动迁移并提示调整项；如果设置来自更高版本，本版本会保留原文件并停用自动缓存维护；损坏设置会先生成备份，再恢复默认值。若另一个实例已修改同版本设置，当前旧实例也会停止自动维护并提示重启，不会覆盖对方的新设置。

点击窗口底部的 导出诊断 可生成 ZIP，其中包含运行环境、设置加载状态、存储摘要、FFmpeg 来源和近期事件。导出前会移除缓存路径、用户目录、令牌、URL 私密部分以及已知的视频标题和分段名；该操作只读取 FFmpeg 状态，不会触发下载或初始化。
