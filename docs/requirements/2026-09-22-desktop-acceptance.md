# 桌面需求验收清单

对应 [2026-09-22 需求基线](2026-09-22-desktop-baseline.md)。R 编号引用该文档，A 编号用于测试、缺陷和后续实现的追踪。

状态：以下为完整验收门槛，未因部分自动化通过而整体打勾。2026-09-23 已执行的自动回归、真实 Electron 合成库测量和仍待完成项见 [实施记录](2026-09-23-implementation-status.md)；历史回归或单次 CI 通过不等于真实桌面发布验收。

本清单不是 `docs/acceptance/` 下用于 Release 转正的真实 JSON 记录，也不修改现行校验器要求。正式发布时仍须针对最终包完成实际桌面测试。

## 验收记录要求

每次实际执行记录提交 SHA、构建/包身份、系统/桌面/会话、CPU/RAM/磁盘类型、数据集身份、视频数与分 P 数、执行步骤、原始结果、时间、测试人和缺陷链接。含敏感路径的日志先脱敏，不提交真实私人缓存。

自动化优先使用可丢弃的隔离目录和合成媒体；删除、恢复、重名和故障注入不得对用户真实缓存直接试验。人工播放使用最终包及实际系统文件关联、mpv/VLC。

## 产品与安装

- [ ] A01 / R01-R02：桌面仍可使用扫描、搜索、播放、导出、回收站、维护、设置、统计及诊断；移除 CLI 未切断 Host 或共用处理能力。
- [ ] A02 / R02：solution、专属测试、开发说明、CI 和发布包均不再要求独立 CLI；不新增桌面免确认删除、绕过回收站删除等替代入口，历史 Release 与 Git 历史未被修改。
- [ ] A03 / R03：Windows 安装版与 ZIP 均使用内置 Host 正常启动，不要求用户另外安装 Node.js/.NET；Linux 日常功能可用，永久删除/清空限制明确且不能绕过。

## 扫描与查找

- [ ] A04 / R04：只保存一个目录；切换时验证新目录并正确替换当前库，不生成多库合并视图。
- [ ] A05 / R04：新配置默认启动扫描；关闭后重启不扫描。已有关闭选择、无有效目录、未记住目录和保存了搜索词的情形均不会绕过用户选择触发扫描。
- [ ] A06 / R04：手动刷新有效；软件自身删除/恢复后更新相关列表；外部目录变化不被误称为实时自动同步。
- [ ] A07 / R04：混合正常、未完成、损坏及不可访问条目，正常内容仍入库；默认排除未完成，打开开关后按规则展示；视频与分 P 计数不混淆。
- [ ] A08 / R04、R13：问题超过 100 条时明细有截断提示、总数完整；定位仅解析当前索引绑定的合法条目，任意路径、过期索引及越界/链接替换安全拒绝，诊断导出脱敏。
- [ ] A09 / R05：标题、UP 主、BV/AV 默认可搜，分 P 名称默认不参与且开关可用；已保存的用户选择及已有桌面高级规则保留，清空搜索恢复列表，不重新扫描磁盘。
- [ ] A10 / R05、R13：连续输入时新查询抢占旧查询；旧成功/失败/取消不覆盖当前结果，同窗口搜索取消不影响其他窗口或媒体任务，索引失效结果不进入查询缓存。

## 选择与只读操作

- [ ] A11 / R06：视频级与分 P 级选择互斥；从一种勾选切换到另一种时清空原集合，仅打开或切换详情不修改选择。
- [ ] A12 / R06：跨主列表页选择多个视频，以及跨视频/详情页选择多个 P，均保留完整目标；总数、完整清单与清空入口一致，重复勾选不生成重复目标。
- [ ] A13 / R06：修改查询条件、重新扫描、切换目录或失效索引后不沿用旧选择；选择规模超过接口允许范围时明确告知，不能静默截断后执行。
- [ ] A14 / R06、R13：提交准备/导出后继续搜索、翻页、查看详情，实际任务仍只处理提交时的快照；新的副作用操作与目录切换被阻止。

## 播放

- [ ] A15 / R07：跨页以乱序点击选择视频或 P，实际队列仍按库列表顺序及 P 序号排序、去重；准备后只调用一次播放器启动。
- [ ] A16 / R07：单项直接交接、多项本地 M3U8；中文及特殊路径有效，标题换行被清理，远程路径/不安全链接拒绝，未引入队列拖排功能。
- [ ] A17 / R07：系统关联、mpv、VLC 分别成功/缺失/启动失败，失败时不启动替代播放器；成功文案不声称实际播放完成。文件关联效果另做真实桌面人工验证。
- [ ] A18 / R07：部分失败交接成功项并保留完整失败目标，重试仅失败项；全失败和准备取消都不启动播放器。
- [ ] A19 / R08：虚拟时间覆盖超过 6 小时准备、超过 64 产物、并发批次、独立实例清理、重启/崩溃后到期及续期失败。保护期不被其他请求缩短，保护续期不能掩盖转码无进展。

## 导出与转码许可

- [ ] A20 / R09：可直接封装的媒体不重新编码；必须转码时确认前不执行未经许可的转换，清单准确说明涉及项目和影响，未提供新的画质/压缩参数入口。
- [ ] A21 / R09：运行中才发现需转码时，本批不发布并给出新增需求；确认后重试完整目标，未确认不能后台继续完成导出。
- [ ] A22 / R09：复用此前播放生成的转码文件、源文件变化、确认后处理方案变化等情况不能绕过所需许可；可安全复用的已准备产物不重复处理。
- [ ] A23 / R10：单 P、单视频与跨视频多 P 均输出为批次/视频/分 P；多 P 不合成一个视频，中文、非法字符、同名和长路径正确处理。
- [ ] A24 / R10：目标已有批次时整批另建编号目录，原内容及校验值不变；目录竞争或重名冲突不能退回覆盖或发布部分文件。
- [ ] A25 / R10、R13：准备中任一失败、提交前取消、提交后迟到取消与提交故障分别返回真实结果；失败/提交前取消无已发布半批，已完成提交不被标成取消。重试范围始终是整批。

## 回收站与维护

- [ ] A26 / R11：整个视频、一个视频的部分 P、跨视频多个 P 均可移入回收站；确认准确显示目标和数量，其他 P 及库外内容不变，成功后可撤销。
- [ ] A27 / R11：分 P 对应重复/多候选物理目录、目录替换、路径链接及处理前源变化时，实际磁盘目标与确认范围一致；无法可靠绑定时拒绝，不按任意渲染器路径操作。
- [ ] A28 / R11：恢复分 P 时父视频目录存在但该 P 不存在可恢复；同 P 被占用则不覆盖并保留回收站条目，同批无冲突项正常恢复且如实报告部分成功。
- [ ] A29 / R11：旧版本整视频回收站条目仍可安全查看/恢复；新增分 P 条目与撤销、分页、统计配合正常；不可信/未来格式仍安全拒绝，失败不丢失可恢复源数据。
- [ ] A30 / R11、R03：Windows 永久清空需确认文字并核对完整当前集合和身份；确认期间条目改变则拒绝；Linux 不开放该操作，也不能经 IPC 绕过。
- [ ] A31 / R12：自动维护只清理受管且不受保护的可重建产物；原缓存、导出目录及回收站保持不变。空间不足仅提示，不自行清空这些区域。
- [ ] A32 / R12：原有存储统计、策略设置和手动维护入口保留，活动/最近使用/受保护产物不误删；平台限制与跨进程安全约束不被后台清理跳过。

## 取消、停滞与结果展示

- [ ] A33 / R13：有效进展持续超过 10 分钟仍运行；无有效进展会请求取消。重复、回退、乱序、阶段循环、等待、耗时增长、其他请求和保护定时器均不掩盖停滞。
- [ ] A34 / R13：首次取消立即显示正在取消，重复触发只提交一次取消；30 秒从取消请求发出起算且不被进度延长，到期后待确认仍跟踪。随后成功/取消/失败按最终结果展示，不强杀 Host，不自动重试，不允许重复副作用操作。
- [ ] A35 / R13：Host 退出无最终结果显示无法确认，用户核对前限制副作用操作；旧 Host 迟到的输出、退出、错误及写入回调不影响新实例请求。
- [ ] A36 / R07、R10-R13：结果面板不混淆部分成功、全失败和取消；播放仅重试失败项、导出重试整批、恢复保留冲突项。明细分页不缩短汇总或实际重试集合。

## 性能与规模

- [ ] A37 / R14：准备 10,000 条视频且包含多 P 的数据集，记录分 P 总数、分布、异常样例、匹配比例及数据集身份；不只使用每视频一 P 的全匹配后端夹具。
- [ ] A38 / R14：在指定 Windows 机器上测量已索引桌面端到端搜索，含 350 ms 防抖，目标停止输入至当前结果可见不超过 1 秒；测量翻页交互至内容可见，目标不超过 500 ms。
- [ ] A39 / R14：预先固定重复方法，记录原始耗时和分布、冷热状态、机器配置及峰值/常驻内存观察；记录超目标样例，不挑选最快一次代表全部。扫描和转码另记环境、规模与耗时，不设置统一总时限。
- [ ] A40 / R14、R13：真实长任务中滚动、搜索、详情与取消状态可响应；确定性测试检查缓存命中不重新筛选排序、失效/取消结果不缓存。保留 50,000 条辅助压力记录，不将其冒充本次正式桌面规模承诺。

- [ ] A41 / R15：CI、构建脚本、校验值、文档与未来验收记录一致对应 Windows EXE/ZIP、Linux DEB/RPM 四类桌面包；未把内部 Host 当成需要移除的 CLI。
- [ ] A42 / R15：用本地夹具验证完整记录、缺项、失败、版本/提交不符、资产集合不符、被替换包及 SHA 不符都按预期处理；预发布标签不能转正。新旧资产集合不能混为同一合格记录，不追溯改写旧 Release。
- [ ] A43 / R03、R15：最终 Windows 10/11 安装包与 ZIP，Ubuntu GNOME、Debian GNOME/KDE、Fedora 至少一种 GNOME/KDE 实际桌面会话完成相应检查；文件关联、mpv/VLC 与 Linux XWayland 真实验证单独记录。
