## 明确边界

- 导出处理来源证明当前仅在 Host 会话内可信，重启后旧产物会重建；不将不明来源的 MP4 当作无损结果。
- 当前兼容转码方案为必要的 AAC 音频转换并复制视频轨；视频复制及音频兼容处理仍失败时报告失败，不暗中增加视频重编码。
- 导出在复制前和提交前复核物理目录/链接，比较源、受管产物和实际暂存文件 SHA，校验期间持只读租约。Windows 父目录重命名要求释放子文件句柄，最终释放到重命名之间仍不是对同账号恶意持续替换目录项的 OS 级完整事务防护；不作这种额外安全承诺。
- 分 P 多个物理候选无法唯一绑定时拒绝删除，并报告原因，不猜测应删除哪个目录。
- 整视频删除沿用移动整个视频目录的行为，包含未完成/未索引内容，确认框明确说明；显示的逻辑 P 数标注为索引中数量。分 P 删除才严格限定到已选 P。
- 部分用例的自动验证不代表 [44 项完整验收清单](2026-09-22-desktop-acceptance.md) 已全部完成，清单保持待完整核验。
